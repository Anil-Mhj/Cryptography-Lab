# Cryptography Lab

This repository contains the implementation of various cryptography algorithms and techniques in C, structured across multiple labs.

## Labs Overview

- **Lab 1**: Ciphers
- **Lab 2**: Modulo Operations
- **Lab 3**: Number Theory
- **Lab 4**: Encryption Algorithms
- **Lab 5**: AES and DES

## Contents

Each lab folder contains C programs that demonstrate different cryptographic algorithms. The programs are designed to be simple, educational examples of cryptography techniques.

## Installation

To run the programs, you'll need a C compiler. Here's how to set up and run the programs:

1. Clone this repository:
   ```bash
   git clone https://github.com/Anil-Mhj/Cryptography-Lab.git
   ```

2. Navigate to the directory of the lab you want to run:
   ```bash
   cd Cryptography-Lab/Lab-1  # for Lab 1
   ```

3. Compile the C program:
   ```bash
   gcc Lab_1/program.c -o program
   ```

4. Run the compiled program:
   ```bash
   ./program
   ```
